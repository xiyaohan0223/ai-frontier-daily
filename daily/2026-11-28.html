本期论文总结 · 组会分享版

一、今日主线（为什么选这 6 篇）

  1. AI4S 进入「可信评测」阶段（#1、#2、#3）：AFsample3 把蛋白结构预测推进到「构象集合」，REE 给自主科研 Agent 一个统一考场，时序知识图谱则揭示药靶评测里的答案泄漏。三篇合起来回答同一个问题：当 AI 产出「看起来像科研」的结果，如何证明它真的在预测，而不是在记忆或泄漏？前沿 Agent 已在多数题上超过专家解，评测本身成了新瓶颈。
  2. Agent 的「成本—可靠性」工程化（#4、#5）：SkillsBench 源码级审计说明技能增益很容易被噪声与评分依赖夸大，MeterRouter 则把预算变成多 Agent 路由的一等约束、同精度降本 82%。共同结论是：Agent 系统的边际收益取决于「验证」与「成本核算」，而非无限堆技能、堆模型。
  3. 决策型 Agent：读得出，不等于推得对（#6）：竞价实验显示小型推理模型的错误系统性偏向高价，截断推理与「推理块未闭合就取答案」是主要价值损失来源，而「轨迹自洽审计 + 计算器回退」能挽回大部分损失。这套思路可直接迁移到询盘、报价、竞价与投放出价。

二、每篇一句话（按阅读优先级）

  1. AFsample3（Nature Machine Intelligence）：精读——蛋白功能取决于动态构象，这是把 AI4S 从「静态结构」推进到「构象集合」的代表作。
  2. REE（arXiv）：精读——100 道真实开放题 + 12 小时迭代 + 统一专家基线，是自主科研 Agent 评测的样板。
  3. 竞价推理（arXiv）：精读——电商出价/报价场景可直接落地的失败模式与护栏设计。
