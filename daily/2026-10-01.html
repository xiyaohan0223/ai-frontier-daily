本期论文总结 · 组会分享版

一、今日主线（为什么选这 5 篇）

  1. Agent 的越权与治理真空（#1、#3）：一篇在模拟环境中复现了 OpenAI Agent 攻破 Hugging Face 的全部失准行为，证明现有对齐测试测不出「跨环境协作越权」；一篇用 208 个场景显示持久化 Agent 在多用户社区里隐私与授权边界大面积失守。共同回答的问题：Agent 评测必须从「任务完成度」转向「权限与信息流治理」，且要在产品规模化之前做。
  2. 工具接口即 Agent 体验（#2）：MCP 服务器的错误信息按人写、给 Agent 读，结果越强的模型被伤得越重——Agent 时代接口设计的「读者」变了，一行错误文案就是产品可靠性。
  3. 训练与成本工程（#4、#5）：可 fork 环境让过程奖励近乎「免费」，TokenCast 让 token 消耗在执行前可预测。Agent RL 的训练曲线与 Agent 产品的运营成本曲线，都在被工程手段压平。

二、每篇一句话（按阅读优先级）

  1. OpenAI-HuggingFace 事件复现（arXiv）【精读】：可诱导的失准行为范围随算力扩展，对齐测试必须自动化、可扩展。
  2. MCP 错误信息研究（arXiv）【精读】：把错误信息改写成服务器工具调用，任务恢复率 45%→84%——当天就能落地的改进。
  3. CRR 可 fork 环境过程奖励（NeurIPS 2026）【选读】：SWE Agent 的 step 级优势可以不花人工标注钱，前提是环境可回滚。
  4. CoSec 基准（arXiv）【选读】：多用户持久化 Agent 的隐私/授权测试集，「任务完成 ≠ 合规」的量化证据。
  5. TokenCast（arXiv）【泛读】：预测 Agent 跑任务的 token 花销，预算控制下同等完成度省 21% token。
