一、今日主线（为什么选这 5 篇）

  1. AI4S 从「辅助工具」走向「自主生产者」（#1）：Prompteina 把「自然语言 → 全原子蛋白质结构」做成生成式范式，让蛋白质设计逼近文生图的易用性。这是大卫·贝克团队把 AI4S 又推进一格——设计目标从「给序列/骨架」升级为「说人话」。
  2. 物理智能与长程 Agent 的「地基」之争（#2、#4）：GroundingPI 主张「精确 grounding 是物理智能的感知底座」，一个 4B 模型在 34 个基准上超过更大的 GPT-6 Astra；Scaling Agentic Data 则从数据规模化角度撑起长程终端 Agent。一个向下扎根感知、一个向上拓展时程，合起来回答「Agent 要跑得远，靠什么打底」。
  3. Agent 的可控性与经验复用，是产品化的真瓶颈（#3、#5）：Thinking Inertia 发现推理模型「被叫停仍停不下来」的思考惯性（成本 + 可控性隐患）；Relevance≠Applicability 指出个人 GUI Agent「检索到经验 ≠ 会激活使用」。对做电商 Agent 的团队，这两条直指记忆系统与运行时护栏的设计核心。

二、每篇一句话（按阅读优先级）

  1. Prompteina：【精读】自然语言直接生成全原子蛋白质结构 + 配套数据集，AI4S 标志性进展，本期最值得读。
  2. GroundingPI：【精读】小鹏 4B grounding 基础模型，34 基准 SOTA、超 GPT-6 Astra，把「感知锚定」确立为物理智能地基。
  3. Thinking Inertia：【选读】Stanford，LLM 被告知停止仍继续思考的惯性现象，推理成本与可控性的直接警示。
  4. Scaling Agentic Data：【选读】阿里，长程终端 Agent 的数据规模化路径，对自建 Agent 训练管线有参照。
  5. Relevance Does Not Imply Applicability：【泛读】NTU，个人 GUI Agent 的「经验激活」难题——检索到 ≠ 用得上。

三、组会讨论题

  • Prompteina 的「自然语言 → 结构化生成」范式，能否迁移到电商（如「一句话 → 商品详情页 / 营销素材 / 合规文案」的结构化可控生成）？评分与约束函数从哪里来？
  • Thinking Inertia 显示推理模型「停不下来」，我们的电商 Agent 在长任务里该如何设置「思考预算」与硬停止，避免 token 与延迟失控？
  • Relevance≠Applicability 指出「检索到经验 ≠ 会用」，Accio 卖家 Agent 的记忆系统该如何从「经验检索」升级到「经验激活」——在正确的时机把正确的过往策略真正用起来？
