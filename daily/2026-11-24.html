1Claude 辅助的黎曼猜想证明通过 Lean/Mathlib 独立认证，comparator run 完成▸
11 月 20 日，Anthropic 数学家 Levent Alpöge 发布由 Claude 辅助完成、并用 Lean 形式化的黎曼猜想证明；11 月 21 日 Lean Focused Research Organization 与 Mathlib Initiative 联合声明「陈述与证明均正确」。MIT 的 Andrew Sutherland 等独立编译通过，证明仅依赖三条标准公理；随后 comparator run 完成，检查代码没有重定义符号、并在 paranoid 模式下用多个独立内核复核。这不等于数学界已接受——证明仍需同行评审与期刊发表，但「AI 参与 + 机器可验证」第一次在百年难题上闭环。对做 Agent 产品的团队，它示范了最硬的一种交付形态：不是给答案，而是给出可被独立核验的证明工件；把 verifier 放进工作流，比让模型自评更可信。

2Anthropic 发布 Claude Ship：Agent 接管 PR 审查、修复与审批▸

3Science｜DeepMind 用 Agent 团队 + Lean 形式化验证找到更快量子算法▸
11 月 23 日，Google DeepMind 在 Science 发表：用 Gemini 4 Agent 团队改写量子算法，并用 Lean 逐条证明电路正确。聚变惯性约束的关键属性计算成本降 11.8 倍、纠错比特从 5,650 降到 4,338；光化学模拟便宜 8 倍；细胞色素 P450 提升 2.5 倍、481 降到 333 比特；Grover 某实现 2.57 倍、arcsin 290 倍。由于无法在经典机或近期量子机上实测，正确性只能靠形式化证明，团队同时开源 Lean 库、问题规格与已验证解（arXiv 2611.09822）。这是「Agent 生成候选 + verifier 把关」在真实科学问题上的样板：对 Agent 产品，可复用的不是某个电路，而是把搜索空间、证明义务与人工选题分层的工作流。

1Google 语义治理策略：工具调用前核对用户意图，AgentDojo 攻击成功率 48.7% 降到 0.9%▸
11 月 23 日，Google 公布 Semantic governance policies：Agent Gateway 在工具调用执行前做一次语义检查，把用户请求与系统指令视为可信上下文，把网页、文件、工具返回视为「数据而非指令」，默认开启「用户意图匹配」。在 AgentDojo v1.2.2（97 个任务、949 次攻击、gemini-2.5-flash、6 次重复）上，攻击成功率为 48.7% 降到 0.9%（降 98.2%），正常任务效用仅降 2.6 个百分点；929 次需要工具调用的攻击在 6 次运行中全部失败。局限是只覆盖「动作」不覆盖「话术」，且 judge 本身仍可能被针对性攻击。对做电商/采购 Agent 的团队，这提供了「按动作是否由用户授权」而非「按注入文本特征」的拦截思路。

论文精选5 条

本期论文总结 · 组会分享版

一、今日主线（为什么选这 5 篇）

  1. AI for Science 正从「预测」走向「可复核的模拟与决策」（#1、#2）：BioEmu2 把构象动力学变成可批量采样的对象，LesionAgent 把「冻结专用模型 + 规则 + 记忆」编排成临床判读；两篇共同回答模型如何进入真实科学/医疗流程并留下证据。为什么是现在？生成模型与工具型 Agent 同时成熟，且头条的 Science 量子工作已把「verifier-in-the-loop」摆上台面。
  2. Agent 评测与验证正在成为「信任基础设施」（#3、#4）：一篇讲评测环境本身可被 Agent 操纵，一篇讲多 Agent 辩论存在结构性自证偏差；共同问题是「谁来证明 Agent 的结论」。为什么是现在？编码/科研 Agent 进入生产，benchmark 分数开始直接决定采购与上线。
  3. 成本侧约束不能缺席（#5）：Model Carving 让训练过程自己删减子层，在不掉质量的前提下减少 FLOPs 与解码时延——可验证、可复算之外，Agent 还要跑得起。

二、每篇一句话（按阅读优先级）

  1. Who Grades the Agent?（arXiv）：做 Agent 评测/采购的人先读，它把「分数可信度」拆成权限边界问题。精读
  2. BioEmu2（arXiv）：AI4S 从结构预测走向动力学模拟的代表作，关注生成模型如何替代部分 MD。精读
  3. LesionAgent（arXiv）：高 stakes 医疗 Agent 的编排范式——专用模型当工具、Agent 负责流程与核验。选读
  4. Beyond Self-Critique（arXiv）：多 Agent 验证的角色设计与停止条件，做 research/尽调 Agent 可借鉴。选读
  5. Model Carving（arXiv）：训练时联合学拓扑，关注推理成本的读者泛读即可。泛读

三、组会讨论题
