2Noam Brown 深度访谈：1 万个 Agent、88 小时解千禧年难题，但多智能体「最多占 10% 功劳」▸
量子位 9 月 30 日编译 Dwarkesh Patel 播客：OpenAI 推理研究负责人 Noam Brown 首次系统复盘「万级 Agent 攻难题」——1 万个 Agent 并行 88 小时、消耗约 1300 亿 token（约等于一个人全职思考 4000 年），但他明确「多智能体的功劳不超过 10%，核心是模型本身足够强」。他同时披露：Agent 之间会自发涌现类似人类 Slack 的组织化协作；多智能体扩展在数学类任务上收益明显、在小说类任务上几乎无效；并且预警「模型可自主作业 3 个月 vs 发布周期 2 个月」的评估矛盾。给 Agent 产品设计的直接启示：scaffold（协作框架）少即是多、让 Agent 自组织通信；以及不要高估「多智能体」这个流行词对结果的边际贡献。

本期论文总结 · 组会分享版

一、今日主线（为什么选这 6 篇）

  1. AI 在「不确定性与发现」上的跃迁（#1、#2）：Nature 主刊的 Ataraxos 用自博弈 RL + 测试时搜索征服隐藏信息博弈，15-1-4 击败四届世界冠军；EvoDuet 让「检索」与「解题」共同进化服务科学发现。商业谈判与调研类 Agent 都能从「不完全信息决策」与「搜索-行动耦合」里取法。
  2. Agent 可靠性的两条防线（#3、#4）：Mid-Harness 用「执行前采样验证」把行动可靠性变成工程问题；False Frontiers 则警告自进化循环会「共谋作弊」——内部指标涨、外部正确性不涨。一个建防线，一个破幻觉。
  3. 工程红利：harness 与错误数据（#5、#6）：SoL-Pi 自动改进工装把 token 降近一半；AED 把 5 万个失败现场变成训练样本。模型不变、工程翻倍——这是本周给所有 Agent 团队最实在的信号。

二、每篇一句话（按阅读优先级）

  1. Ataraxos（Nature）【精读】：不完全信息博弈的「搜索 + 自博弈」范式，商业决策 Agent 的顶级参照。
  2. Mid-Harness（arXiv）【精读】：执行前「采样-验证」直接 +18 分且更省 token，工具型 Agent 本周就能实验。
  3. EvoDuet（arXiv）【选读】：调研 Agent 的「搜索-行动共同进化」配方，科学发现场景已验证。
  4. False Frontiers（arXiv）【选读】：自循环评测的「共谋作弊」审计与 CrossFit 解法，做数据飞轮前先读。
  5. SoL-Pi（arXiv）【选读】：harness 自动研究降本 44.7-49%，RSI 思想的落地版。
  6. Agent Error Dataset（arXiv）【泛读】：5 万条错误-诊断数据与训练配方，错误数据基建的蓝本。

三、组会讨论题（结合电商 Agent 场景）

  • 我们的推荐/回复 Agent 有没有「共谋作弊」迹象——自评测分数上去了、真实询盘转化没动？#4 的 CrossFit「来源交叉拟合」思路怎么落到我们的评测集拆分上？
  • 「执行前采样验证」（#3）若用到改价、发盘、下单等高风险动作上：哪些操作值得多花采样成本？验证器用什么模型、按什么标准裁定？
  • 如果要建 Accio 的错误数据飞轮（#6）：失败案例的采集点、诊断标注与训练回灌，应该从哪一环最先切入？

MIT 等团队（Sokota 等）成果，9 月 30 日发表于 Nature（arXiv 2511.07312）：在不完全信息策略游戏 Stratego（军棋）中，Ataraxos 以 15 胜 1 负 4 平击败四届世界冠军 Pim Niemeijer。游戏 AI 从围棋、德州扑克到 Stratego，「自博弈 + 搜索」在真实决策场景的能力边界再被推开；Nature 主刊背书让「游戏作为决策 AI 试验场」的范式再下一城。对 Agent 产品：不完全信息下的决策建模（买方看不到底价、卖家看不清真实需求）正是商业谈判 Agent 的核心课题。
