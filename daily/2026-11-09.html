1ICLR 2027 首轮审稿翻车：让作者解释「标准差」，评语开头是「Certainly! Here is a review」▸
11 月 5 日 ICLR 2027 首轮评审开放后，11 月 8 日机器之心汇总了多起争议案例：有审稿人要求作者解释什么是标准差，有三位审稿人给出几乎逐字相同的模板意见，第三位甚至把大模型常见的「Certainly! Here is a review of the paper」开场白原样留在正式评语里；还有人被分到不熟悉的方向却仍给出高置信评分。UT Austin 的 Jiaxin Pei 指出关键问题：LLM 能给任何论文列出上百条「局限性」，却分不清哪些只是正常取舍、哪些真正动摇核心结论，于是评审越来越长，真正该拒的理由反而被淹没。ICLR 2027 已要求署名 3 篇及以上投稿的作者至少审 6 篇，允许有限度使用 AI 但必须披露并提交最初独立撰写的评估与全部对话记录，违规可拒掉其所有投稿；公开讨论持续到 11 月 18 日，12 月 16 日出结果。对 Agent 产品，这是一次现成的「AI 评审 AI」压力测试：评价器的校准、可追溯与责任归属，比生成更多意见更重要。

2AI 主刀活体小鼠脑手术：3 台之后学会纠错，越界时会拒绝▸
Exin Therapeutics 把 19 个基因治疗载体、摄像头和立体定位臂交给 Agent，只留一句任务目标「减少癫痫发作」；它自己分析发作扩散路径、选择增强 GABA 能抑制信号的载体，把注射点定在外侧鼻周皮层，5 分钟内注入 250 nL（约 5 亿病毒基因组颗粒），全程 32 次截图检查出血与药液回流。更关键的是边界设计：开颅仍由人完成，持证兽医手持物理急停，注射量设硬上限；Opus 5.5 因涉及活体直接拒绝、Opus 5 在活体操作前停手，最终 Sonnet 5 完成手术，而 GPT-6.1 Sol 在后续 3 台手术中经外科医生纠错后学会修正坐标漂移。它说明长时程物理 Agent 的可用性不取决于「敢不敢做」，而取决于「何时拒绝 + 谁能在环内纠正」；但目前没有同行评审数据，演示不等于疗效。

本期论文总结 · 组会分享版

一、今日主线（为什么选这 5 篇）

  1. 从「能生成」到「能被验证」（#1、#2、#3）：PharmAgents2 用湿实验回环，MCPHallu 用失败子类型，TCSExam 用 Lean 与可执行 checker，三篇都把评价锚在可复核的证据上。为什么是现在：Agent 进入科研与生产后，demo 的说服力在下降，过程证据开始决定预算。
  2. 过程比总分更能定位问题（#2、#3、#5）：子类型排名漂移、专家过程 rubric、课程跳级测试，共同在回答「到底是哪一步坏了」，而不是只给一个成功率。
  3. 推理成本从「多采样」转向「精准重采样」（#4）：先定位首个错误步，再只重跑错误步与后缀，是预算约束下更务实的推理时扩展路线。

二、每篇一句话（按阅读优先级）

  1. PharmAgents2（NeurIPS 2026）：Paper2Skill + 并行自扩展探索，在 LpxH、JAK1 和未知靶点三个真实案例里给出经湿实验支持的发现，并把「过程 rubric」做成基准；AI for Science 与多 Agent 团队必读，精读。
  2. MCPHallu（NeurIPS 2026 Poster）：358 个任务、36 个生产 MCP 服务器、14 个 Agent，平均 0.642，Unreachable Goal 通过率仅 23.2%，且子类型排名平均漂移 6.9/13；做 MCP 工具链的团队精读。
  3. TCSExam（arXiv）：100 道 TCS 研究题，定理证明由 Lean kernel 核验，Lite 版 20 题与 Full 排名 ρ=0.93；想用 AI 做形式化科研的选读。
  4. StepBack（NeurIPS 2026）：定位首个错误步后只重采样该步与后缀，在 7 个基准上追平 self-consistency 且 token 最多省 41.26%；推理成本优化必看，选读。
  5. BabyTheorist（arXiv）：只给前后视觉变化、不给程序标签，考「观察式理论获取」，7 个基线均远低于上限；世界模型研究者的泛读材料。

三、组会讨论题

  • 电商询盘 Agent 遇到缺货、无权限这类「不可达目标」时，奖励与审计该怎么设计，才能鼓励它承认做不到，而不是继续调工具或谎称完成？（#2）
  • 能否把 PharmAgents2 的专家过程 rubric 搬到采购与上架流程？当过程分与成交率冲突时，谁有最终拍板权？（#1）
  • MCPHallu 显示不同失败类型的模型排名并不一致，我们的工具域回归集该多大、多久更新一次，才不至于被单一榜单误导？（#2、#3）
1PharmAgents2（NeurIPS 2026）：把药物发现做成连续决策，湿实验验证新靶点▸
系统从公开来源抽取可迁移的科学决策知识（Paper2Skill），再让并行 Agent 继承研究上下文，在靶点、假设和发现策略上自扩展；同时发布 PharmAgents-Bench v0.1，含 121 道题、9 类决策场景和 3 个端到端任务，用专家定义的过程 rubric 评分。三个真实案例中，LpxH 提出此前未报道的别构位点并筛到新抑制剂骨架，JAK1 优先共价抑制策略并找到有活性化合物，从已知活性分子出发还反推出一个新结合靶点，均由后续湿实验支持。对 Agent 产品，最值得借鉴的是「过程评分 + 实验回环」，而不是让 Agent 直接下结论。

2MCPHallu（NeurIPS 2026 Poster）：358 个任务拆开 MCP Agent 的推理、执行与记忆幻觉▸
基准在 36 个生产 MCP 服务器、隔离容器中构造 358 个任务，用 Branch Collapse、Unreachable Goal、Tool Misuse、Context Forgetting 四种子类型做结构性触发，而不是事后归因；14 个前沿 Agent、5012 条轨迹平均只有 0.642，Unreachable Goal 仅 0.458、通过率 23.2%，模型常继续发起工具调用或直接宣称完成。更刺眼的是子类型排名平均偏移 6.9/13，Branch Collapse 与 Unreachable Goal 几乎不相关（r=-0.12）。选 MCP Agent 不能只看一个总分，要按工具域和失败类型建自己的回归集。

3TCSExam（arXiv）：100 道理论计算机科学研究题，Lean 核验，GPT-6 Astra 与 Opus 5.5 领跑▸
