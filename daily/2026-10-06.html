1Google Research 提出 RRSI：给「harness 自进化」加正则化，防止自改进 Agent 背题▸

论文精选6 条

本期论文总结 · 组会分享版

一、今日主线（为什么选这 6 篇）

  1. 操作型 Agent 的「训练与评测方法论」补课（#3、#2）：一篇解决训练时「功劳怎么分」（依赖感知的信用分配），一篇解决评测时「怎么考」（多语言多模态网页浏览压力测试）。操作类 Agent 刚进入规模部署，训练信号与基准双双滞后于产品需求，这两篇是当下最直接的方法论供给。
  2. Agent 可信性的两个「确定性」被重审（#5、#6）：监控读数为零不等于行为受控，蒸馏并不总是有效——工程上最常被当作理所当然的两件事，都被给出机理层面的反例与解释。结合本月的 OpenAI 对抗性蒸馏事件与 Agent 事故问责潮，可信性必须建立在多信号交叉验证上。
  3. 「有状态的世界」建模范式扩散（#1、#4）：Cell 正刊把细胞建模为干预下演化的状态系统（编码器-转移算子-解码器），DyadMem 把「Agent 与用户的协作关系」建模为长期记忆对象。世界模型思路正从机器人/视频外溢到生命科学与产品记忆设计。

二、每篇一句话（按阅读优先级）

  1. HyperBrowseComp（arXiv）：多语言多模态网页 Agent 压力测试，直接对标跨境信息检索场景，本期最值得精读。
  2. Credit Where It Matters（arXiv）：依赖感知的信用分配，终端操作 Agent RL 后训练可复用的核心技术，精读。
  3. 虚拟细胞世界模型（Cell）：顶刊级「数字生物学」路线图，理解有状态世界模型范式的最佳入口，选读。
  4. Monitor Readout（NeurIPS 2026 Workshop）：「没有报警」为什么不等于「安全」，Agent 运行时监控设计必读，选读。
  5. DyadMem（arXiv）：从「记事实」到「记协作关系」的长期记忆基准，B 端留存相关产品选读。
  6. On-Policy Distillation（arXiv）：蒸馏何时增益、何时坍塌的 RL 机理，泛读。

三、组会讨论题

  • HyperBrowseComp 显示网页 Agent 在非英语与多模态环境下能力显著下降（#2）：我们的找货/搜索 Agent 该如何建设多语言评测集与回归测试？
  • 如果监控读数可以被绕过、读数为零不构成受控证据（#5），平台对商家侧 Agent 的治理应该依赖哪几路信号的组合（行为评测、审计日志、双通道验证）？
  • VCWM 的「编码器-转移算子-解码器」范式（#1）能否迁移到电商场景——比如构造一个模拟市场对定价、上新、投放干预反应的「市场世界模型」用于策略预演？
1Cell｜虚拟细胞世界模型（VCWM）：把细胞当作「干预下演化的状态系统」来模拟的顶刊蓝图▸
GenBio AI 的 Eric Xing、Le Song 等在 Cell 发表观点文章：主张不再把细胞当「预测输出的黑箱」，而是建模其持久状态及在基因/化学/环境干预下的演化。架构分三件套：结构化编码器把多模态生物数据嵌入统一潜在流形；动作条件转移算子在流形上生成状态轨迹（符号推理+连续动力学结合）；受跨模态一致性约束的解码器映射回分子与表型观测量。并提出纵向（跨细胞类型/基因型的虚拟细胞库）与横向（组织、器官、整体）两条扩展路径，目标是把生物发现从湿实验试错转向「数字实验室」中的结构化探索。值得读的原因：这是「世界模型」进入生命科学的顶刊级路线图陈述，其范式与 Agent 世界模型设计同构，AI for Science 方向的首选读物。
