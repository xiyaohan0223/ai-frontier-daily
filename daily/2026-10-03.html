1AIBuildAI 开源 PostTrain Agent：递归自进化 Agent 登顶 PostTrainBench，46.6 分逼近人类专家▸
给定基座模型、目标能力和单张 H100 十小时预算，这个 RSI Agent 自主设计后训练算法、构建数据、写代码、跑实验并迭代改进，全程无人介入。在 PostTrainBench 上以 46.6 分超过所有前沿模型与 Agent 系统（Locus 45.6、Claude Code + Fable 5 为 41.8），距人类专家基线 51.1 不足 5 分。关键增量来自两处：468 份带 URL 与日期的知识文件库（工作流/方法/数据集/框架四个子库）让 Agent 依据证据而非记忆决策；「元搜索」让搜索拓扑本身成为 Agent 的输出（37 种可组合模式）。同为 Claude Opus 5 底座，它比 Claude Code 高 11.6 分——系统设计的价值已超过换一代模型。全部代码与知识库开源，是把「AI 研发 AI」从口号变成可复现工程的重要样本。

2openJiuwen X-Router 首发自演进模型路由：Agent 越跑越省，实测 Token 成本降 44.6%-51.4%▸
华为 2012 实验室等联合构建的开源 Agent 平台 openJiuwen 发布智能路由引擎：在 Agent 与模型之间加一层「看菜下饭」的决策层——离线刻画 + 分钟级在线刷新每个模型的能力画像，按任务复杂度五档分派，并把每一次执行结果（质量/成本/时延/成败）写回状态层，用 Contextual Bandit 持续修正选模策略。实测 PinchBench 上得分 70.70%（与全云基线仅差 0.66 个百分点），模型调用成本从 $11.11 降到 $6.16（-44.6%）；Terminal-Bench 上 cost 模式成本降 51.4%、成功率仍达 Opus 的 95.2%。架构上「算法纯函数 + 状态外置」的解耦设计值得抄作业——状态丢失只降级为冷路由而不失败。对多模型混部的 Agent 产品，这可能是规模化前必须补的一块基础设施。

3何恺明团队 NAT-ARC：看猫片学会抽象推理，ImageNet 预训练打通视觉路线 scaling 瓶颈▸
MIT CSAIL 何恺明组的 ECCV 2026 论文：不依赖 LLM，把 ImageNet MAE 预训练的 encoder 直接插入纯视觉 ARC 解题流程，0.6B 单模型在 ARC-1 上拿到 63.4% pass@2，三种预训练策略集成后达 70.2%——用约四分之一的参数量逼近 8B LLM 方案（The ARChitects 71.6%）。更有分量的发现是 scaling 曲线：无预训练时模型从 large 到 huge 反而掉点，加上自然图像预训练后一路向上。注意力可视化显示，从未见过 ARC 格子的模型会自动把「从草地里认出猫」的前景/背景分离能力迁移到抽象格子。自然世界与抽象推理共享同一套表征——这是对「视觉基础模型表征通用性」的一次漂亮正面证明。

2arXiv｜Trust the Critic More：AC2 用动作块信用分配，2.5 倍少算力超越 GRPO 峰值▸
斯坦福团队（Kaiyue Wen、Tengyu Ma 等）提出 Actor-Critic with Action Chunking（AC2）：不再把每条轨迹 rollout 到终点才拿奖励，而是让学到的 critic 给 10k token 的「动作块」打分，配合 local readiness（仅在 critic 对该问题足够准时启用）与参考解注入。Qwen3-4B 在 FineProofs-RL 训练后，IMO-ProofBench 上以 2.5 倍更少的解码 FLOPs 超过 GRPO 峰值（18.5%）。核心洞见是「学到的 critic 可以被信任」——这直接改写了长程任务 RL 的算力经济学。
