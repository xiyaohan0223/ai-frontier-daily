OpenAI 于 10 月 26—27 日公布三项由模型参与完成的研究：证明所有维度下的局部光滑猜想，从而一并解决挂谷（Kakeya）猜想与自 1991 年悬置至今的 Stein 限制猜想；在复杂性理论中给出指数时间假设（ETH）不成立的论证；并为包括纯 Yang–Mills 在内的若干四维量子场论给出存在性构造（质量间隙仍未解决）。数学与 CS 部分已同步公开自然语言论文与 Lean 形式化证明，物理部分的形式化正等待包括 David Gross 在内的外部专家评审。对产品与 Agent 设计的启示是「可验证产出」正在成为硬指标：形式化证明让模型输出可以被机器逐行检查，这比 benchmark 分数更能撑起高风险场景的信任，也预示 Agent 的交付物会越来越多地绑定可机检的验收器。

本期论文总结 · 组会分享版

一、今日主线（为什么选这 6 篇）

  1. RSI 从概念走向工程（#4、#6）：Skill∞ 给出技能层递归改进的可执行闭环，Trustworthy RSI 则系统梳理其失效模式，两篇合起来正好是「怎么用」与「怎么不出事」。
  2. Agent 的验收标准正在被重写（#1、#2）：根因分析里简单 harness 打败复杂多 Agent 编排，协同编程要看渲染结果而非单测，共同指向「评测即架构」。
  3. 主动性成为第三条能力轴（#3、#5）：Proactive AI 综述把主动性形式化为独立维度，Proof-of-Agentness 处理主动 Agent 在开放 Web 上的身份与可追责问题。

二、每篇一句话（按阅读优先级）

  1. Free to Look, Free to Reason（arXiv）：先做简单 harness，再谈多 Agent 编排，精读。
  2. Co-Design Bench（arXiv）：用渲染一致性评测多模态协同编程，精读。
  3. Proactive AI for Superintelligent Agents（arXiv 综述）：主动性应与智能、对齐并列，精读。
  4. Skill∞（arXiv）：技能级递归自我改进的闭环实现，选读。
  5. Proof-of-Agentness（arXiv）：在 Web 上验证 Agent 身份，选读。
  6. Trustworthy RSI（arXiv）：自我改进的失效模式与安全带，泛读。

三、组会讨论题
