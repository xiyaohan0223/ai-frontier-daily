论文精选6 条

本期论文总结 · 组会分享版

一、今日主线（为什么选这 6 篇）

  1. AI for Science：LLM 开始「改进科学计算内核」本身（#1）：不是用模型去拟合性质，而是让语言模型发现更快的分子弛豫优化算法。这标志 AI4S 从「预测层」下沉到「数值方法层」，对任何跑大规模仿真/结构优化的科研流水线都是提速杠杆，本期优先级最高。
  2. Agent 的工程成本与评测补课（#2、#5）：一篇用硬数据说明 agentic retrieval 提升 8.7 分 nDCG 却贵 160 倍、慢 160 倍，一篇提出 UndoBench 把「任务能力」与「出错后的恢复能力」分开评测。二者共同回答一个产品级问题：Agent 更强了，但代价（延迟/成本/可恢复性）到底是多少、怎么量化。
  3. 生成模型的效率与对齐新招（#3、#4、#6）：开源音视频「同生」基础模型 Kandinsky 6.0、用 20 个样本做群体化个性对齐的 APO、以及把「64 候选强采样」压进单次解码的 OPPD 蒸馏。主线是——如何在有限数据/算力下拿到更强的生成与对齐效果，都是可直接迁移到产品训练管线的方法。

二、每篇一句话（按阅读优先级）

  1. Optimizing the Optimizer（arXiv · AI4S）：LLM 自动发现更快的分子弛豫算法，AI4S 下沉到数值方法层，本期首推精读。
  2. NeMo Retriever（arXiv · NVIDIA）：agentic retrieval 的召回增益 vs 160 倍成本/延迟实测，检索型 Agent 选型必读，精读。
  3. UndoBench（arXiv）：把 Agent「做对」与「纠错」能力分开评测，长链路业务 Agent 评估设计选读。
  4. APO（arXiv · UW/HKUST）：20 个样本经聚类做个性化对齐，冷启动个性化 Agent 的思路，选读。
  5. Kandinsky 6.0 Video（arXiv）：MIT 开源的同步音视频基础模型，多模态生成同学选读。
  6. OPPD（arXiv · USC/Intel）：把强采样收益蒸进单次生成，数学/推理小模型提效，泛读。

4arXiv｜APO：用聚类 + 20 个样本实现 LLM 的协同个性化对齐▸
UW/HKUST 提出 APO（Approximate Pareto Optimality）：数据稀缺下的个性化对齐两阶段框架——先按用户共享的「瓶颈偏好目标」聚类，再为每簇元训练专属初始化，使新用户仅凭 20 个样本即可适配自己的对齐器。在 Fed-ChatbotPA 上用 Llama-3.2-3B-Instruct 把加权分提到 0.83（最佳基线 0.78），UltraFeedback 上最高 +17.1% hypervolume，工程上用 LoRA（r=8）+ DPO 损失 + 4bit NF4 量化。为什么值得读：它给「个性化 Agent 冷启动」提供了一条低成本路径——不必为每个用户收集大量偏好数据，而是借「相似群体」的共享结构做初始化。对需要按商家/买家群体做偏好个性化、又苦于单体数据稀疏的电商 Agent，这套「聚类 + 小样本适配」思路可直接借鉴，选读。

5arXiv｜UndoBench：把工具型 Agent 的「任务能力」与「恢复能力」分开评测▸
UndoBench 指出：现有基准只测 Agent「能不能把任务做对」，却忽略了「做错之后能不能识别并回滚/纠正」。它把任务胜任力（task competence）与恢复能力（recovery capability）解耦，专门构造需要撤销错误工具调用、修正副作用的场景来评测工具型 Agent。为什么值得读：真实业务 Agent（下单、改价、发消息、调库存）的错误代价高，「可撤销 + 会纠错」比「一次做对」更决定用户信任。对做经营类/交易类 Agent 的团队，这套评测思路提示我们：应建立「误操作可回滚率、纠错成功率」的独立回归基准，并明确哪些副作用动作必须可逆，选读。

6arXiv｜OPPD：把「64 候选强采样」的收益蒸馏进单次生成▸
USC/Intel 提出 On-Policy Power Distillation（OPPD）：把推理时「幂采样（power sampling，多候选择优）」的高成本，前移进训练阶段，使学生在单次生成中就能恢复大部分收益。在 Qwen2.5-Math-7B 上把 MATH500 从 66.8% 提到 89.8%、GSM8K 从 63.8% 提到 91.1%，单次生成即超过「64 候选幂采样」2.4-3.5 分、超过 GRPO 3.8-5.4 分，且无需参考答案、可与 GRPO 叠加再涨最多 9.3 分，代码已开源。为什么值得读：它示范了「把推理时的搜索成本换到训练时」的经典提效范式——对需要低成本部署的推理/数学小模型（含 Agent 内部的规划、校验子模型）是可直接复用的后训练技术，泛读。
