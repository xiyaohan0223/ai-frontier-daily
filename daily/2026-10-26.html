论文精选6 条

本期论文总结 · 组会分享版

一、今日主线（为什么选这 6 篇）

  1. AI 自主做科学，从「答题」到「产出知识」（#2、#6）：SplatLab 把 3DGS 一个具体领域的科研闭环交给 Agent 自主推进，MolLean 则给化学推理装上「过程可验证」的形式语言。合起来回答同一个问题：当 Agent 声称「我发现/我证明了」，凭什么信？答案正在从看答案对错，转向审计研究过程本身。
  2. 开放环境里，Agent 的真实能力与真实风险（#1、#5）：OpenDS-World 用 200 个真实网页任务量出深度搜索 Agent 的天花板（最强模型 39%），Agent Mosaic 则系统化识别多 Agent 系统里的机密泄露路径。能力与风险是同一枚硬币：跨源取证能力越强，越需要配套的信息流治理。
  3. 实时多模态交互的两个切面（#3、#4）：Heartbeat Thinking 把用户「还在说话」的时间变成工具调用的准备时间，WeVisOne-VL 把视觉感知从物体级打通到像素级。交互带宽（延迟、粒度）仍是语音/视觉 Agent 体验的决定性变量。

二、每篇一句话（按阅读优先级）

  1. OpenDS-World（arXiv）：真实开放网络上的深度搜索基准，最强前沿模型 39% vs 人类 21.1%——做搜索/询盘类 Agent 的同学必读，精读。
  2. SplatLab（UCSD，arXiv）：单领域「自主科学发现」闭环的最新完整样本，AI4S 方向本期优先关注，精读。
  3. Heartbeat Thinking（蚂蚁国际，arXiv）：语音 Agent 边听边推理的工程范式，工具覆盖 +16pp、最终延迟 -36.4%，做语音导购/客服的直接参考，精读。
  4. Agent Mosaic（USC，arXiv）：给 Agentic LLM 系统的机密泄露做系统化识别，Agent 治理团队选读。
  5. WeVisOne-VL（腾讯，arXiv）：物体到像素的统一视觉感知，多模态基建方向选读。
  6. MolLean（arXiv）：化学推理的过程可验证语言，泛读即可，思想可迁移到其他可验证领域。

三、组会讨论题

  • OpenDS-World 里模型靠工具协调取胜、但长程搜索管理仍是瓶颈（#1）：Accio 的采购搜索 Agent 该把「何时停」和「证据够不够」做成什么显式机制？
  • Agent Mosaic 揭示多 Agent 协作会意外泄露机密（#5）：我们的 Agent 团队（选品/询盘/跟单）之间，哪些上下文应该默认隔离？
  • SplatLab 与 MolLean 都强调「过程可验证」（#2、#6）：电商 Agent 的产出（选品报告、报价建议）能否也设计一套过程级验证语言，而不是只靠人抽查结果？
