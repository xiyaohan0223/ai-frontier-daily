1Meta 发布 Muse Wonder / Wonder Full：Active Memory + Active Focus 写进模型本体，「个人超级智能」首次有了公开榜单▸
10 月 12 日 Meta 超级智能实验室（MSL）发布 Muse Wonder 与 Muse Wonder Full：前者经 Meta Model API 开放（$4/$20 每百万 token、1M 上下文），后者分数更高但仅随 Muse Code 订阅提供。两项核心能力首次成为旗舰模型标配——Active Memory 支持跨会话沉淀与主动检索用户相关记忆，Active Focus 让模型在长任务中「遇阻改道、目标不漂移、重大动作前请示」；官方配套发布 Personal Superintelligence Index、SWE-Marathon（57.5，大幅领先 Opus 5.5 的 46.3）、MemoryBench、FocusBench 等一组新基准，AA 智能指数 56 分与 Sonnet 5.5 并列。对 Accio：如果 Meta 的判断成立，「记忆 + 专注」就是下一代模型竞争的主维度——商家经营 Agent 的跨会话记忆（店铺、偏好、历史决策）与「何时请示」的边界设计，应从工程补丁升级为选型评估项。

2阿里 QwenGyre 公开弹性 RL 框架：超长程 Agent 训练提速 1.85 倍，旗舰模型 48 步提点 6pp▸
阿里通义团队公开 QwenGyre（arXiv 2609.33848）：面向超长程（xlong-horizon）Agent 的端到端在线强化学习框架——在不停机的前提下于 rollout 与训练之间弹性重分配 GPU，并用轨迹处理器重建分支历史、为部分进展打分、去除冗余路径，专治长任务 RL 最贵的两个坑：执行方差导致的 GPU 空转与非线性分支带来的轨迹冗余。规模化到 Qwen 3.8 2.4T 旗舰（单条 rollout 约 70 万 token）时，NL2RepoBench 48 步内从 52.5% 提升到 58.5%，对比 Colocate / Async 方案最高提速 1.85x / 1.78x。意义：Agent 长任务的「训练基础设施」正在成为模型能力的第二增长曲线。对 Accio：选品→询盘→履约→复盘这类周期数周的经营任务若要走强化训练，算力账要先按这套弹性架构来估。

3GitHub 上线「推送归属」公测：Committer 必须与推送者匹配，封堵 AI Agent 伪造提交身份的攻击面▸
10 月 12 日 GitHub 推出推送归属（Push Attribution）公开预览：为每次推送记录经过认证的推送者身份，并新增分支保护条件「Committer 必须与推送者匹配」——commit 的 committer 元数据邮箱必须属于推送者已验证邮箱之一，否则拒绝推送；目前面向 GitHub Enterprise 限量预览。背景是编码 Agent 大规模代为提交代码后，commit 作者字段可被任意伪造，导致审计、许可证追溯与供应链信任全部失真。这不是普通功能更新：当 Agent 成为主要「提交人」，「谁真的按下了快门」正在变成新的信任基础设施。对用 Agent 写代码的团队：CI 审计与合规检查会越来越多依赖「已认证提交者」断言，内部流水线设计应提前对齐。
