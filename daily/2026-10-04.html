1亚马逊 & 杜克新研究：一条 rollout 只监督一个 token，推理能力不降反升▸
在 On-Policy Distillation 中，对每条 rollout 随机保留仅一个 token 的梯度信号（其余全部 mask），学生模型推理能力仍显著提升；若改选教师-学生分歧最大的 1-2 个 token，甚至能匹配或超过全信号训练，并反超教师本身。该现象跨数学/代码、Qwen3 与 Llama 系列、OPD 与 PPO-RLVR 均成立。更反直觉的是：极端稀疏监督下学生与教师的输出分布反而更远——学习不是模仿。万分之一监督仅更新约 10% 网络参数。如果成立，后训练的算力经济学要重算：不是每个 token 的信号都值得付钱。

2arXiv｜Agents Are Systems, Not Models：Agent 评测应把「配置」当变量，54% 的方差来自重复运行本身▸
Cordelia Schmid、Zeynep Akata 等人的新基准研究：让编码 Agent 完成四项科研任务（找到并正确运行已发表的专用模型），系统考察任务信息、推理、自我验证、时间预算、底座模型五个配置维度。结论很有冲击力：约 54% 的结果方差来自同一配置的重复运行（而非配置变化）；喂给 Agent 的信息量影响超过时间预算和模型大小；prompt 里要求「验证一下」几乎不改变验证行为，而给一个专门的验证工具则显著改变。对评测体系的启示：报一个成功率数字意义有限，Agent 应作为可配置系统来评测；对产品团队的启示：想获得某类行为（如自查），给工具比给指令有效得多。

3arXiv｜Global Coherence：每个 Agent 都对、团队却错了——多智能体的「共享状态」不可能定理▸
单作者论文提出「全局一致性」问题：各 Agent 局部决策都合法，联合结果却非法，其根源是共享状态缺失而非模型智能不足。论文给出 Observation-Aliasing 不可能定理：若 k 个不可区分的世界需要两两互斥的动作，任何策略的随机最坏成功率不超过 1/k——更多推理、角色、消息、样本都无法恢复丢失的区分。实验极具说服力：决定性事件可见时同一前沿模型 40/40，被隐藏时仅 12-17/40（接近随机）；tau2-bench Telecom 上常规 current-state 检查 0.07 分，harness 层强制 commit 语义则 1.00。对多 Agent 编排的直接忠告：让 harness 而非模型拥有共享状态与提交权。
