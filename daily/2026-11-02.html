论文精选6 条

本期论文总结 · 组会分享版

一、今日主线（为什么选这 6 篇）

  1. Agent 的「内部状态」正在被认真建模（#2、#3）：一篇给 Agent 加可学习的「对他人信念」，一篇把长期记忆拆成情节与关系两张表。共同回答的是同一个问题——当上下文不再是唯一答案，Agent 该把「状态」存在哪里、怎么更新、怎么压缩。这是从「更长的 prompt」转向「可维护的状态机」。
  2. 评测从「终局对不对」转向「过程变没变、代价多少」（#4、#5）：DynaRev 把「用户中途改需求」写进基准，Real Cost of Context 证明输入上下文的算力与能耗是超线性的。两篇合起来说明：长会话 Agent 的正确性与经济性，都必须按过程计量。
  3. 不更新参数，也能扩展能力边界（#1、#6）：反应先例检索让冻结的模型覆盖训练外的新反应，可倒带的交互证明让弱验证者监督强模型。共同指向一个判断——推理时的外部结构（先例库、可回放检查点），可能比再训一轮更划算。

二、每篇一句话（按阅读优先级）

  1. 反应先例替代参数更新（arXiv）：必须精读，尤其适合做企业知识 Agent 的同学——「检索先例 + 冻结参数」在化学上把 Top-1 从 13% 拉到 58%。
  2. DynaRev 动态目标修订（arXiv）：建议精读，电商 Agent 的「买家改需求」几乎就是它的实验设定，且给出了「保状态别重置」的实证。
  3. 长期记忆：情节 + 关系双表（arXiv）：选读，LoCoMo 90.2% 的工程化记忆架构，可直接对照我们的买家画像方案。
  4. 上下文的真实成本（arXiv）：选读，prefill 的二次项是把「长上下文免费」叙事打回成本模型的一记实锤。
  5. EpiAgent 认知自博弈（arXiv）：选读，多智能体议价场景的方法论参考，训练成本偏高。
  6. Rewindable Interactive Proofs（arXiv）：泛读，理论味重，但为「Agent 审计可回放」提供了正式模型，价值在于长期。

三、组会讨论题

  • 买家在对话里改规格是常态（#4）。我们的会话状态现在有哪些是「重置式」的？能不能做到「重写指令但保留购物车/询盘上下文」？
  • 如果记忆应该拆成情节与关系（#3），那「买家上次砍价到多少」属于哪一类？跨境场景里的公司归属、采购集团关系又该怎么存、怎么脱敏？
  • 上下文成本随时长二次增长（#5）。我们现在的套餐是按「次」还是按「token」？如果按 token，长会话用户的毛利是正的吗？
1arXiv｜用「反应先例」替代参数更新：逆合成预测在训练覆盖之外也能泛化▸
作者用 271 万条反应，按反应类型与时间切分训练/检索覆盖，只扩充检索库、冻结模型参数：被排除在训练外的反应类型，Top-1 从 13.0% 提升到 58.0%（历史测试集）、从 4.9% 提升到 23.1%（时间外推集）；仅用 2017 年前数据训练的模型加上检索后，可以追平甚至超过用 2025 年前数据训练的无检索模型。更关键的是，不做任务微调，先例检索让 14 个通用模型在两个测试集与 USPTO-50K 上全面提升，最强的一个超过了全部 8 个专用模型。结论对企业 Agent 很硬：把领域「先例」做成可检索资产，比再训一轮更能扩展能力边界。
