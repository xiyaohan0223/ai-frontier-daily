1阿里国际站张阔详解 Commerce Agent Bench：107 项真实电商任务前沿模型仅 61.7% 通过，Accio Work 以 1/3 成本完成▸

1Zenity 披露 AgentCorruption：一条提示可接管 AWS 账户内全部 AgentCore Agent（已修复）▸
10 月 8 日，安全公司 Zenity Labs 披露 AWS Bedrock AgentCore 的串联漏洞「AgentCorruption」：攻击者只需向一个对外可达的 Agent 发出一条提示，即可窃取凭证、跨 Agent 边界蔓延并投毒记忆，最终接管同一 AWS 账户与区域内的所有 AgentCore Agent；泄露面包括会话内容、源代码、Secrets Manager 凭据与 OAuth token。根因是默认配置过宽（未屏蔽的实例元数据访问、过大的默认执行角色）叠加记忆注入，AWS 已于 9 月 29 日完成缓解（新 Agent 强制 IMDSv2、收紧默认权限）。对构建在托管 Agent 平台上的团队：上线前应把「最小权限、实例元数据封锁、记忆写入审计」做成自查清单——平台默认值不等于安全值。
