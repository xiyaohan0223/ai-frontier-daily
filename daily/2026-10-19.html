1Anthropic 内部报告：AI Agent 工时已达人类 6:1，初级技术招聘占比从 27% 跌至 9%▸

1NAVER AI Lab 提出 Speculative Forcing：自回归视频生成「按 token 提前定稿」，提速 1.5×▸
NAVER AI Lab（arXiv:2610.22347）发现少步自回归视频生成器对每个 token 都跑完整去噪是浪费——很多 token 早期就已接近最终结果。Speculative Forcing 把中间「干净估计」当作草稿，预测哪些 token 可安全提前接受并冻结（其 KV 仍作为后续 token 的上下文），并提供免训练与学习式两种验证器。在 LongLive 上以约 1.7 步/token 匹配四步生成器质量、提速 1.5×（41.7/37.8 fps）；在 Lingbot-World 2.0 上以约 2.5 步/token 提速 1.35×。对做商品视频/直播生成的团队，这是把「流式视频生成」推向实时的降本关键路径。

1arXiv｜Waypoint-OPD：用教师 RL「早/晚策略位移一致性」门控在线蒸馏（HF 668 赞）▸
策略位移蒸馏把教师 RL 前后的对数概率差当作监督信号，但「端点位移」无法反映训练中途局部动作偏好是否一致演化——同一端点位移可能由相互加强或部分抵消的早/晚位移造成。Waypoint-OPD 引入同一 RL run 的中期教师 checkpoint，在学生访问过的前缀上比较早/晚相对动作偏好，按方向一致性对端点位移做门控（方向相反则抑制），仅多一次冻结教师打分。用 Qwen3-4B 教师、在 Qwen3-8B/14B/30B-A3B 学生上做数学与代码推理，6 个「领域×学生」设定全部取得最高域均分。对做模型蒸馏/能力迁移的团队是可直接借鉴的低成本改进。
