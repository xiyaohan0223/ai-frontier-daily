1谷歌开源 Harness²：给大模型装「运行中自改外挂」的 RSI，GLM-5 装 WorkBuddy-Bench 反超 Gemini 3.5 Flash▸
谷歌开源 Harness²——在 Harness 层做递归自我改进（RSI）：让模型在运行中自己魔改外挂代码、系统提示词、工具链与技能库。它用「双层递归」解决 RSI 两大死穴：任务级递归在无标准答案时做对照实验，改进级递归把每次魔改沉淀成可复用经验。效果夸张：装配 Harness² 的 GLM-5 在办公基准 WorkBuddy-Bench 上直涨 11.5 分、反超原生 Gemini 3.5 Flash，已支持 OpenCode 与 Codex。这是「Agent 自进化」从论文走向可安装工具的标志——我们的商家 Agent 若长期服务同一商家，类似机制可让工作流越用越贴合；但要警惕无 ground truth 场景下的「改坏自己」，先在灰度商家上做 A/B 对照。

2peec.ai 实证「发布假统计，就被 LLM 引用」：Agent 检索层的信任危机▸
peec.ai 做了个冷酷实验：故意发布包含虚假统计数据的文章，随后观察到这些数字被多个 LLM 和 AI 搜索引擎当作事实引用传播（HN 320+ 赞）。结论是「先发布、后引用」的检索增强管线对内容真实性几乎没有校验——模型不知道「谁在说」，只知道「说了什么」。对做 Agent 的团队这是必须直面的风险面：当我们的导购/选品 Agent 引用外部市场数据生成选品建议时，污染链路是一样的。建议给 Agent 的检索层加来源分级（一手统计/二手转述/无来源），关键数字强制溯源到原始出处，并在产物里保留引用链供人工抽查。
